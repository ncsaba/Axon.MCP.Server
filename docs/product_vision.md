# Product Vision

Axon provides a queryable code understanding layer for AI development workflows.

## Focus Areas

- Reliable multi-language indexing for Python/Java/web stacks
- Fast retrieval of symbols, relations, and architecture context
- MCP-first tooling for IDE and agent integration
- Integration-friendly deployment with PostgreSQL + Redis infrastructure

## Near-Term Priorities

- Improve parser coverage for Java and config/doc formats
- Strengthen cross-file relation quality and ranking
- Expand architecture summaries and request-flow tracing
- Keep infra and devcontainer defaults aligned for integration testing
